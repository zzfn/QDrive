# QDrive

QDrive 是夸克网盘的非官方命令行客户端。它使用非官方接口，服务端变化或账号风控可能导致命令失败；不要声称尚未实际验证的操作已经成功。

## 准备

先确认 `qdrive` 可执行文件可用；在 QDrive 源码目录也可以使用 `./qdrive`，或通过 `go run ./cmd/qdrive` 运行。查看实际支持的命令：

```sh
qdrive --help
```

如果没有安装，参考仓库 README 的安装或构建说明。Linux 安装脚本需要已有 GitHub Release，且会替换目标目录中已有的 `qdrive`；先向用户说明再安装。

## 登录与安全

- 扫码登录请让用户在自己的终端运行 `qdrive login --qr`，并用夸克 App 扫码。不要要求用户发送二维码、Cookie 或 token，也不要捕获或展示二维码。
- 如果用户选择手动输入 Cookie，也由用户在自己的终端操作 `qdrive login`。不要读取、打印或传输本地凭据文件，不要把凭据写进命令行参数、日志或仓库。
- 登录信息以明文保存在本机用户配置目录的 `qdrive/credentials.json`。`qdrive logout` 只清除本地凭据，不撤销服务端会话；仅在用户要求时执行。
- 登录后可以用 `qdrive ls /` 验证；登录信息过期或接口报错时，如实说明，不要编造结果。

## 常用命令

```sh
qdrive ls /                       # 列出根目录
qdrive ls '/目录名'                # 列出指定目录
qdrive upload './本地文件' '/目录名' # 上传单个文件
qdrive download '/目录名/文件名'    # 下载到当前目录
qdrive download '/目录名/文件名' './保存路径'
qdrive create '新目录' '/'
qdrive rename '/文件名' '新名称'
qdrive move '/文件名' '/目标目录'
qdrive copy '/文件名' '/目标目录'
qdrive --json ls '/'
qdrive user
qdrive info '/文件名'
qdrive share-list
```

命令中的路径要正确引用，避免空格或特殊字符被 shell 解释。上传、创建、重命名、移动和复制会修改网盘；下载会写入本地。只按用户的请求操作，目标路径不明确时先确认。删除必须得到用户明确授权，并使用 `qdrive delete --yes <路径>`；删除目录还需要 `--recursive`。创建分享、转存或取消分享也必须先得到用户明确授权，不要把分享链接或提取码写入不必要的日志。转存的同名冲突行为未知，需告知用户并使用 `--yes`；“已受理”不代表已完成。如果结果为 `OUTCOME_UNCONFIRMED`，先检查网盘状态，不要盲目重试。

`ls` 默认输出制表符分隔的类型、字节数和名称，使用 `--json` 可获得 JSON。下载支持文件及目录，并尝试单文件断点续传，条件和遗留文件见 README。目录下载默认 4 个并发任务，`--workers` 可调为 1–16；已存在的本地文件会报告冲突，不会覆盖或当成成功。目录上传会合并同名目录，对发现的同名文件报冲突并继续其他文件；并发修改目标时无法保证不覆盖。目录中有空文件、符号链接或特殊文件时不会开始上传。当前不支持上传续传或上传空文件。新增的账号、文件管理、分享、JSON 输出和传输改进尚未测试，不要声称已验证可用。其他能力以 `qdrive --help` 和仓库 README 为准。
